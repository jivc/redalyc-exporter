# Illustrative example

This folder holds the files exported in the illustrative example described in the accompanying article.

Search string: `bullying AND university AND mental health`

| File | Description |
|---|---|
| `redalyc_bullying_and_university_and_mental_health_<date>_n<records>.ris` | All results, RIS format |
| `redalyc_bullying_and_university_and_mental_health_<date>_n<records>.bib` | All results, BibTeX format |
| `redalyc_bullying_and_university_and_mental_health_<date>_n<records>.csv` | All results, CSV format |
| `..._registro.txt` | Search log for the export above |
| `..._n107.ris` and its `_registro.txt` | Same search with year (2021, 2022) and language (Spanish) filters applied |

Redalyc's collection grows over time, so running the same search later may return a different number of records. The search logs record the date, the filters and the counts of each export.
